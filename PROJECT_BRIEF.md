# Project Brief — NOIRÉ

Luxury furniture e-commerce concept. Source: Figma file `rnJK1jkIsIq6Mnz6f9aiv6`, page `💌 3 – UI Design`.

## Brand colours

| Token | Hex | Use |
|---|---|---|
| `--color-bg` | `#02060F` | Page background |
| `--color-white` | `#ECEEF4` | Headings, light buttons |
| `--color-ivory` | `#F8F6F2` | Accent lines in display titles |
| `--color-accent` | `#BB3A64` | Active states, social icons, hearts |
| `--color-text` | `#B2BCD3` | Body copy |
| `--color-muted` | `#7B8497` | Inactive labels |
| `--color-surface` | `#1C1F27` | Cart, order summary, account panel |
| `--color-navy` | `#1A2B51` | Style guide navy |
| `--color-gradient-end` | `#170249` | Essence section gradient |
| Borders | `rgba(255,250,250,.3)`, `#40444B` | Cards, inputs |

## Typography

- **Cormorant Garamond** (headlines, uppercase): 300/240 & 300/300 (Essence), 140/140 (Balance, Collection), 136/109 (Hero), 112/112 (section titles), 80/80 (page titles), 60/60 (panel titles), 46/55 Bold (logo). Weights 400/500/700.
- **Raleway** (body, UI): 32/43 SemiBold (price), 24/32, 20/27 (labels, uppercase), 20/24 SemiBold (buttons), 18/24 (body), 16/22, 14/19 (small).
- Letter-spacing −2% on all sizes (e.g. −2.24px at 112px).

## Spacing & shapes

- Frame 1920px, content inset 60px, 200px between home sections.
- Card padding 24px, grid gaps 20–21px, button height 64px, inputs 64px.
- No border radius (square UI), 1px hairline borders. Only round elements: hero hotspots, social icons.
- Effects: background blur 22.8px on the hero glass card, 4px on the "Discover more" tile.

## Interactions

Hero hotspots, cart drawer, wishlist hearts, product carousels with progress bar, filter accordions + price range, product accordions, colour swatches, quantity steppers, checkout steps with validation, order-history accordion.

## Breakpoints

Desktop 992px+ (ideal 1920) · Tablet 768–991 (834) · Mobile landscape 480–767 (550) · Mobile portrait 320–479 (360).
